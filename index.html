Guia de Atalhos de Leitura

Principais comandos para navegar rapidamente usando seu leitor de tela preferido.

NVDA / JAWS (Windows)
  • H: Mover para o próximo cabeçalho.
  • 1 a 6: Ir para cabeçalho do nível correspondente.
  • K: Mover para o próximo link.
  • F: Mover para o próximo campo de formulário/botão.
VoiceOver (iOS / macOS)
  • VO + Seta Direita/Esquerda: Ler próximo item ou item anterior.
  • Rotor (Girar dois dedos): Alternar entre cabeçalhos, links e botões.
  • Toque duplo: Ativar elemento selecionado.
TalkBack (Android)
  • Deslizar para direita/esquerda: Mover foco entre os itens.
  • Deslizar para baixo e para cima: Mover por cabeçalhos ou links.
  • Toque duplo com 1 dedo: Selecionar item focado.
